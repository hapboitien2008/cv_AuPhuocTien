## 🚀 HƯỚNG DẪN ĐƯA TRANG WEB LÊN MẠNG INTERNET CHO TẤT CẢ MỌI NGƯỜI XEM

### Cách 1: Dùng Tiiny Host (Nhanh nhất - Có link sau 10 giây)
1. Truy cập trang web: https://tiiny.host
2. Kéo thả file nén `AuPhuocTien_CV_Online.zip` (ở thư mục scratch) vào ô upload.
3. Đặt tên đường dẫn mong muốn (ví dụ: `auphuoctien`).
4. Nhấn **Publish** -> Nhận ngay link online: `https://auphuoctien.tiiny.site` gửi cho bạn bè, thầy cô xem ở bất cứ đâu!

### Cách 2: Dùng Netlify Drop (Miễn phí 100%, chuẩn Web Hosting quốc tế)
1. Truy cập trang web: https://app.netlify.com/drop
2. Kéo toàn bộ thư mục `AuPhuocTien_CV_Online` hoặc file `.zip` thả vào khung nét đứt.
3. Chờ 5 giây là trang web được tải lên toàn cầu với đường link HTTPS tốc độ cao.

### Cách 3: Dùng GitHub Pages (Chuẩn nhất dành cho Dân Công Nghệ Thông Tin)
1. Đăng nhập tài khoản https://github.com
2. Tạo Repository mới đặt tên là `profile` hoặc `cv`.
3. Tải các file: `index.html`, `style.css`, `script.js` và thư mục `assets` lên repository.
4. Vào mục **Settings** -> **Pages** -> Tại mục *Branch*, chọn `main` rồi nhấn **Save**.
5. Link của bạn sẽ có dạng: `https://<ten-github-cua-ban>.github.io/profile/`.
